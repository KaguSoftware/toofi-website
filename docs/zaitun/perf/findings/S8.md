# S8 findings: the rest of the site

Search track S8 of the [optimization plan](../../OPTIMIZATION_PLAN.md), 2026-11-22. Scope: Compounds, Residences, Contact and the story pages (EN and AR), tap response in the finder, the older scene viewport (Bustan Dijla, Shatt Gardens), Arabic font loading, and the admin panel only where it is slow to use. No product code changed.

## How it was measured

On the P0 rig: production build of `main` at 692ea51 (snapshot 580a9777c3), served locally in local mode, measurement lock held, on the charger. Scripts in [scripts/perf/S8/](../../../../scripts/perf/S8/):

- `pages.mjs`: 11 routes × phone (4× CPU, Fast 4G, low tier) and desktop (high tier), three cold loads each, medians. Records layout-shift sources and the LCP element.
- `taps.mjs`: real touch taps (phone) and clicks (desktop) on the finder, six seconds after load with the scene running; Event Timing entries (input delay, processing, next paint).
- `switch.mjs`: `/residences?compound=<id>` cold, time and bytes to a ready scene, then a switch to another compound. On the phone the scene waits behind a "Load 3D" button, so time is from the tap.
- `admin.mjs`: signs in as the demo admin and loads each panel page. Needs `AUTH_SECRET` exported (see rig note 1).

## Ruled out ("no gain")

- Tap response in the finder: 32–48 ms median on both profiles at 4× CPU with the scene running; input delay 16–19 ms (phone) and 1 ms (desktop) is the event queue, not our code (processing 3–8 ms).
- `/compounds`, `/contact`, `/what-we-do`, `/our-story`: no main-thread work worth a fix (blocking 7–22 ms phone, 0 desktop). `/our-story` LCP is its hero image at 1.05 s (phone); the images are already `next/image`.
- Switching between Bustan Dijla and Shatt Gardens: shared model, nothing to save.

## Notes for the rig and the owner

1. `admin.mjs` needs `AUTH_SECRET` in the environment: the rig's clean environment leaves it out and local sign-in then fails in production ("Something went wrong"). I exported a throwaway value for the run; the rig could set one itself for the admin scripts (P0).
2. The admin scope question is still open (STATUS.md, Owner inputs). Result above says it needs no work either way.
3. The shift in S8-1 is in the first 100–1,160 ms, before any scene code: a fallback skeleton is enough, no look gate is involved.
4. The edit-mode inline editor on the public pages was not measured (needs a signed-in site page); `P3` covers its bundle cost.
